# AI 부업 실전 가이드 — 판매 전략 & 실행 플랜

## 1. 목표를 현실적으로 쪼개기

"주당 100만원"을 정가 19,900원 전자책 기준으로 환산하면:

- 100만원 ÷ 19,900원 ≈ **주당 약 51권 판매** 필요
- 플랫폼 수수료(약 20% 가정) 반영 시 실제 정산액은 판매가의 80% → 목표 매출 기준으로는 주당 약 63권 필요

이 숫자를 첫 주부터 달성하기는 어렵습니다. 대신 아래처럼 4주 램프업 계획을 권장합니다.

| 주차 | 목표 판매량 | 목표 매출 | 핵심 과제 |
|---|---|---|---|
| 1주차 | 5~10권 (런칭 할인 9,900원) | 5~10만원 | 상품 등록, 지인·1차 독자 리뷰 확보 |
| 2주차 | 15~20권 | 15~30만원 | 리뷰 3개 이상 확보 후 정가 전환, SNS 홍보 시작 |
| 3주차 | 30권 | 40~60만원 | 오픈채팅방/카페 홍보, 콘텐츠 마케팅(블로그 후기) |
| 4주차 이후 | 50권+ | 70만원~100만원+ | 정기 콘텐츠 발행으로 재구매·입소문 유도, 다른 재능(3~5장) 병행 |

**핵심**: "1주일 만에 100만원"이 아니라 "1개월 안에 주당 100만원 페이스에 도달"을 현실적 1차 목표로 잡으세요. 이미 팔로워/이웃/구독자가 1,000명 이상 있다면 이 타임라인은 훨씬 단축될 수 있습니다.

## 2. 가격 전략

- **런칭 특가**: 9,900원 (14일 한정) — 초기 리뷰·판매 실적 확보용
- **정가**: 19,900원
- **번들 옵션**: 프롬프트 템플릿 PDF(부록) 포함 시 24,900원 — 객단가를 자연스럽게 올리는 방법

가격은 허위로 "원래 5만원인데 할인"처럼 표시하지 않습니다. 실제 할인 기간과 조건을 명확히 표기하세요 (전자상거래법상 표시·광고 규정 준수).

## 3. 채널별 실행 순서

1. **크몽** — 전자책/자료 카테고리에 등록. 재능마켓 특성상 첫 리뷰가 쌓이면 노출이 급격히 늘어남.
2. **유페이퍼 또는 부크크** — 교보문고·리디북스 등 서점 유통 신청 (승인까지 1~2주 소요될 수 있음, 장기 판매 채널로 병행)
3. **본인 블로그/인스타/스레드** — "이 문제로 고민하는 분들을 위해 만들었다"는 스토리텔링 게시물 + 랜딩페이지 링크
4. **관련 오픈채팅방/네이버 카페** — 스팸성 홍보가 아니라, 실제로 도움이 되는 요약 정보를 먼저 공유하고 "더 자세한 내용은 전자책에 담았다"는 식으로 자연스럽게 연결

## 4. 리뷰 확보 전략

- 무료 체험판(1~2장 미리보기 PDF)을 만들어 잠재 구매자에게 배포
- 첫 구매자 10명에게는 "솔직한 리뷰 남겨주시면 다음 개정판 무료 제공" 제안 (금전적 리뷰 대가 제공은 플랫폼 정책 위반일 수 있으니 각 플랫폼 가이드라인 확인 후 진행)

## 5. 사용자(본인)가 반드시 직접 해야 하는 단계

아래 항목은 신원 확인이 필요해 AI가 대신 처리할 수 없습니다.

- [ ] 크몽/탈잉/유페이퍼 등 판매자 계정 가입 + 휴대폰 본인인증
- [ ] 정산 계좌(본인 명의) 등록
- [ ] 통신판매업 신고 필요 여부 확인 (플랫폼 고지사항 참고, 필요 시 정부24에서 온라인 신청)
- [ ] `ebook/AI-부업-실전가이드.pdf` 파일을 각 플랫폼 상품 등록 화면에 업로드
- [ ] `marketing/랜딩페이지.html`의 "구매하기" 버튼 링크를 본인의 실제 판매 페이지 URL로 교체
- [ ] SNS 계정으로 홍보 게시물 업로드 (`marketing/홍보문구.md` 그대로 활용 가능)
- [ ] 매출 발생 시 세금 신고 방법을 국세청 홈택스 또는 세무사와 확인

## 6. 확장 전략 (2개월차 이후)

- 판매 데이터를 보고 잘 팔리는 챕터 주제를 분리해 미니 전자책 시리즈로 확장
- 전자책 구매자 대상으로 "1:1 AI 부업 컨설팅" 옵션(크몽 컨설팅 카테고리) 추가해 객단가 상승
- 리뷰가 쌓이면 3장~5장에서 소개한 다른 수익화 방법(카드뉴스 대행, 상세페이지 카피 등)도 병행해 수익원을 다각화
